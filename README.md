# 🥫 烦恼寄存箱 · Worry Box

一个睡前把盘旋在脑子里的念头「寄存」出来的极简 Web App。
**写下来 → 被接住 → 允许你忘。**

> 让你睡不着的不是"事多"，是"怕忘"。人要的不是更多清单，而是一个可靠的承诺：**有人替你记着。**

---

## ✨ 功能

- **三分类寄存** —— 把念头拆成 `待办 / 担忧 / 念头`。**担忧不当任务**（没有勾选框），它本就不该被解决，只该被承认。这是和所有 to-do 产品的分界线。
- **明确的承诺** —— 倒完一件，系统立刻回一句"收到了，明早 9:00 会提醒你"，按分类给不同措辞。
- **🃏 心灵卡** —— 24 张权威语录卡（一行禅师 / 玛丽·奥利弗 / 鲁米 / 老子 / 里尔克 / 弗兰克尔…），带作者、出处与一句解读；手绘星空图腾背景，文艺楷体。
- **🎵 舒缓背景乐** —— 用 Web Audio 实时合成（有能量、静谧的冥想氛围），零音频文件、离线可用，可开关、音量可调。
- **🧘 10 分钟冥想** —— 接入 **UCLA 正念研究中心（MARC）的慈心冥想引导**（Diana Winston 录制，Creative Commons 授权），真实音频播放 + 计时。
- **明早汇总** —— 待办按优先级排、担忧只"被看见"不列任务、念头轻飘过；"一次都不能漏"的可靠性计数（已送达 / 漏发）。
- **零后端、零账号、纯前端** —— 数据存 `localStorage`，**不上传任何服务器**。

## 🛠 技术栈

纯静态：`index.html` + `style.css` + `app.js`，无构建步骤、无依赖。
- 分类引擎：本地启发式（关键词加权 + 时间线索，可解释、离线）。
- 背景乐：Web Audio API 实时合成。
- 冥想音频：UCLA MARC 外链 `<audio>`（CC 授权）。

## 🚀 本地运行

```bash
# 任意静态服务器即可
python -m http.server 8765
# 然后浏览器打开 http://127.0.0.1:8765
```

直接双击 `index.html` 也能跑，但建议用本地服务器（语音 / 音频策略更稳）。

## 📄 部署到 GitHub Pages

仓库根目录即站点根，直接开启 GitHub Pages（分支 `main`，目录 `/root`）即可。
详见发布时生成的说明。

## 🔒 隐私

所有寄存内容仅存于你本机浏览器 `localStorage`，刷新/重开仍在，**但换设备/清缓存会丢失**，且不会上传。请把它当作"今晚的安心"，而非长期档案。
